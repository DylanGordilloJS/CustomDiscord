# 🎨 Custom ClearVision Transparent - Tema para BetterDiscord

Un tema oscuro, moderno y altamente translúcido para Discord, basado en **ClearVision v7**. Incluye un diseño flotante con efecto desenfoque (*glassmorphism*) para la caja de texto y tonos oscuros estilizados.

## ✨ Características principales
* **Alta transparencia:** Fondos sombreados y translúcidos (`Ash Theme`) para lucir el fondo de pantalla.
* **Caja de texto flotante:** Barra de mensajes redondeada con efecto de desenfoque (`backdrop-filter: blur`) y sombra suave.
* **Colores personalizados:** Acentos en azul vibrante (`#2780e6`) con contraste optimizado para lectura cómoda.
* **Basado en ClearVision v7:** Hereda la estabilidad y compatibilidad del tema base.

---

## ⚙️ Requisitos previos
Para utilizar este tema necesitas tener instalado:
* **[Discord](https://discord.com/)** (Aplicación de escritorio).
* **[BetterDiscord](https://betterdiscord.app/)** instalado en tu cliente de Discord.

---

## 📦 Instalación

1. Descarga el archivo **`CustomClearVision.theme.css`** de este repositorio (puedes hacer clic en el archivo y luego en el botón de descarga *Download raw file*).
2. Abre Discord y ve a **Configuración de usuario** (el ícono del engranaje ⚙️ abajo a la izquierda).
3. Baja hasta la sección de **BetterDiscord** y selecciona **Temas (Themes)**.
4. Haz clic en el botón **Abrir carpeta de temas (Open Themes Folder)**.
5. Mueve o pega el archivo `CustomClearVision.theme.css` dentro de esa carpeta.
6. Regresa a Discord y activa el interruptor del tema.

---

## 🛠️ Personalización (Opcional)
Si deseas cambiar el fondo de pantalla o los colores principales, abre el archivo `.theme.css` con cualquier editor de texto (como VS Code o el Bloc de notas) y modifica las variables dentro de `:root`:

```css
:root {
  --main-color: #2780e6; /* Color principal */
  --background-image: url('TU_ENLACE_DE_IMAGEN_AQUI'); /* Fondo de pantalla */
}
